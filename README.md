# Drone-Induced Distraction Project Website

This folder contains a static GitHub Pages-ready project site.

## Local preview

```bash
cd docs
python3 -m http.server 8000
```

Then open `http://localhost:8000`.

## GitHub Pages

1. Push this repository to GitHub.
2. Open repository settings.
3. In Pages, choose `Deploy from a branch`.
4. Select the target branch and the `/docs` folder.

The site uses local project images and compressed MP4 videos prepared for web publication.
